# Power Manager

Sterownik zasilania i telemetrii DUT dla ECU Platform V2. Repozytorium jest rozwijane niezależnie od ECU Platform; brak integracji z CORE.

Kod roboczy i dokumentacja są przygotowywane na gałęziach funkcjonalnych, a scalanie do `main` wymaga zgody właściciela projektu.

Hardware: KAmod ESP32 POW+RS485, 3 × DFRobot DFR0473, 1 × Adafruit INA228 QT (wspólny pomiar).
